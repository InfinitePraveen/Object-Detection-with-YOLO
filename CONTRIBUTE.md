# Contributing

Thanks for your interest in improving this project.

## Simple Contribution Flow

1. Fork the repository.
2. Create a feature branch.
3. Keep changes focused and easy to understand.
4. Test notebook cells and the Flask application locally.
5. Update `CHANGELOG.md` when your change affects project behavior.
6. Open a pull request with a clear explanation of the change.

## Contribution Guidelines

- Keep the repository structure simple.
- Prefer notebook-based experiments for learning examples.
- Avoid adding a `src/` directory or unnecessary preprocessing modules.
- Do not commit large datasets, model binaries, caches, or generated uploads.
- Keep code readable and beginner-friendly.
- Preserve the CPU-friendly design unless a new feature genuinely requires additional resources.

## Pull Requests

A useful pull request should explain:

- What changed
- Why it changed
- How it was tested
- Any additional dependency or disk-space requirement
